# 🛠️ Функції з параметрами

## 🌟 Історія

Після того як Черепашка навчилася створювати власні команди, вона дуже зраділа.

Тепер вона легко малювала квадрати:

```python
square()
```

Але незабаром у Майстерні винаходів з'явилося нове завдання.

Потрібно було намалювати:

* маленький квадрат 📦;
* середній квадрат 🪟;
* великий квадрат 🏠.

Черепашка замислилася:

> Невже доведеться створювати окремі команди `square_small()`, `square_medium()` і `square_big()`?

І тут вона відкрила ще одну таємницю Python:

> Функції можуть отримувати додаткову інформацію — параметри.

Так народилися **функції з параметрами**.

---

## 🧠 Що таке параметр?

Параметр — це значення, яке передається функції під час її виклику.

Воно допомагає зробити функцію більш гнучкою.

Наприклад, можна сказати:

> Намалюй квадрат зі стороною 50.

або

> Намалюй квадрат зі стороною 120.

---

## 🔧 Як створити функцію з параметром?

Параметр записується в дужках після назви функції.

```python
def назва_функції(параметр):
```

---

## 🚀 Перша функція з параметром

Створимо команду для малювання квадрата будь-якого розміру.

```python
from turtle import *

def square(size):
    for i in range(4):
        forward(size)
        left(90)

square(100)

done()
```

---

## 📌 Що тут відбувається?

Спочатку ми створюємо функцію:

```python
def square(size):
```

Параметр

```python
size
```

зберігає довжину сторони квадрата.

Під час виклику:

```python
square(100)
```

число `100` передається у змінну `size`.

Черепашка фактично виконує:

```python
forward(100)
```

---

## 🎯 Малюємо різні квадрати

Тепер одна функція може малювати квадрати різних розмірів.

```python
from turtle import *

def square(size):
    for i in range(4):
        forward(size)
        left(90)

square(50)

penup()
goto(100, 0)
pendown()

square(100)

penup()
goto(250, 0)
pendown()

square(150)

done()
```

---

## 🧩 Що тут важливо?

Ми написали код квадрата лише один раз.

Але можемо використовувати його по-різному:

```python
square(50)
square(100)
square(150)
```

---

# 🎨 Ще один приклад — трикутник

```python
from turtle import *

def triangle(size):
    for i in range(3):
        forward(size)
        left(120)

triangle(80)

done()
```

## 💡 Параметри можна називати по-різному

Наприклад:

```python
def square(side):
```

```python
def star(length):
```

```python
def flower(petal_size):
```

Головне — щоб назва допомагала зрозуміти, що означає це значення.

---

# 🚀 Два параметри

Функція може отримувати не один, а кілька параметрів.

Наприклад, прямокутник:

```python
from turtle import *

def rectangle(width, height):
    for i in range(2):
        forward(width)
        left(90)

        forward(height)
        left(90)

rectangle(150, 80)

done()
```

Тут:

* `width` — ширина;
* `height` — висота.

---

# ⚡ Головна ідея теми

Звичайна функція виконує одні й ті самі дії:

```python
square()
```

Функція з параметрами може працювати по-різному:

```python
square(50)
square(100)
square(150)
```

Тепер Черепашка не лише створює власні команди, а й може передавати їм потрібні значення! 🚀🐢

---

## ✅ Запам'ятай

| Запис                | Що означає                         |
| -------------------- | ---------------------------------- |
| `def square(size):`  | створити функцію з параметром      |
| `size`               | параметр функції                   |
| `square(100)`        | виклик функції зі значенням 100    |
| `square(50)`         | виклик функції зі значенням 50     |
| `rectangle(150, 80)` | виклик функції з двома параметрами |

📌 **Параметри роблять функції гнучкими: одна команда може виконувати схожі дії з різними значеннями.**
