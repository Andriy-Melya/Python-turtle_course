---

## 🧠 Що таке функція?

Функція — це власна команда, яку ми створюємо самі.

Спочатку ми описуємо, що вона повинна робити, а потім можемо викликати її скільки завгодно разів.

---

## 🔧 Як створити функцію?

Для створення функції використовується команда:

```python
def назва_функції():
```

Після неї записуються всі команди, які повинна виконати функція.

---

## 🚀 Перша функція

Створимо команду для малювання квадрата.

```python
from turtle import *

def square():
    for i in range(4):
        forward(100)
        left(90)

square()

done()
```

---

## 📌 Що тут відбувається?

Спочатку ми створюємо функцію:

```python
def square():
```

А потім запускаємо її:

```python
square()
```

📌 Після виклику черепашка виконує всі команди, які знаходяться всередині функції.

---

## 🎯 Для чого потрібні функції?

Функції допомагають:

* 📝 не повторювати однаковий код;
* ⚡ швидше створювати програми;
* 🧹 робити код охайним і зрозумілим;
* 🏗️ будувати великі проєкти з маленьких частин.

---

## 🚀 Малюємо кілька квадратів

```python
from turtle import *

def square():
    for i in range(4):
        forward(80)
        left(90)

square()

penup()
goto(120, 0)
pendown()

square()

done()
```

---

## 🧩 Що тут важливо?

Ми написали код квадрата лише один раз.

Потім просто викликали:

```python
square()
```

скільки потрібно.

---

# 🎨 Ще один приклад — трикутник

```python
from turtle import *

def triangle():
    for i in range(3):
        forward(100)
        left(120)

triangle()

done()
```

---

## 💡 Функції можна називати по-різному

Наприклад:

```python

```

```python
def flower():
```

```python
def house():
```

Головне — щоб назва допомагала зрозуміти, що робить функція.

---

# ⚡ Головна ідея теми

Звичайні команди вже існують у Python:

```python
forward()
left()
goto()
```

А функції дозволяють створювати власні команди:

```python
square()
triangle()
house()
```

Тепер черепашка може не лише виконувати готові команди, а й вигадувати нові! 🚀🐢


Я б ще додав наприкінці невеликий блок **"Запам'ятай"**, як у попередніх темах:


---

### ✅ Запам'ятай

| Запис | Що означає |
|---------|---------|
| `def` | створити функцію |
| `square()` | викликати функцію |
| `def square():` | створити власну команду |
| відступи після `def` | команди функції |

📌 Функція — це набір команд, який можна запускати багато разів.
